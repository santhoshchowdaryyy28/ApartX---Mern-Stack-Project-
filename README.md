🏢 ApartX – Apartment Management System

ApartX is a full-stack MERN web application designed to simplify apartment community management. It provides separate dashboards for residents and administrators to manage billing, complaints, notices, and resident data efficiently.

🚀 Features

👤 Resident Dashboard

* User registration and login
* View maintenance bills and payment history
* Raise and track complaints
* View notices and announcements

🛠️ Admin Dashboard

* Secure admin login (role-based access)
* Manage residents and apartment data
* Handle complaints and update status
* Generate and manage maintenance invoices
* Post notices and announcements
* View financial reports

🛠️ Tech Stack

* Frontend: React (Vite), Tailwind CSS
* Backend: Node.js, Express.js
* Database: MongoDB (Mongoose)
* Authentication: JWT (JSON Web Tokens)

📂 Project Structure

Frontend/
Backend/

* Frontend handles UI and user interaction
* Backend handles APIs, authentication, and database operations

⚙️ Installation & Setup

1️⃣ Clone Repository

git clone https://github.com/santhoshchowdaryyy28/ApartX---Mern-Stack-Project-.git
cd ApartX---Mern-Stack-Project-

2️⃣ Backend Setup

cd backend
npm install
npm run dev

3️⃣ Frontend Setup

cd frontend
npm install
npm run dev

🔐 Environment Variables

Create a .env file inside the backend folder:

MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
PORT=5000
